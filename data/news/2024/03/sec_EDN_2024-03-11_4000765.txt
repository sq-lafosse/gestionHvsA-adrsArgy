<P STYLE="font: 16pt Arial, Helvetica, Sans-Serif; margin: 0; text-align: center; text-indent: 7.1pt; color: #1F497D"><B>PRESS RELEASE
</B></P>

<P STYLE="font: 14pt Arial, Helvetica, Sans-Serif; margin: 0; text-align: center"><B>&nbsp;</B></P>

<P STYLE="font: 14pt Arial, Helvetica, Sans-Serif; margin: 0; text-align: center"><B>&nbsp;</B></P>

<P STYLE="font: 14pt Arial, Helvetica, Sans-Serif; margin: 0; text-align: center"><B>EDENOR surpasses investment level by 17% in 2023
compared to the previous year. </B></P>

<P STYLE="font: 14pt Arial, Helvetica, Sans-Serif; margin: 0; text-align: center"><B>As from 02-16-24 an increase in the CPD, which includes
an automatic monthly adjustment, was approved.</B></P>

<P STYLE="font: 14pt Arial, Helvetica, Sans-Serif; margin: 0; text-align: center"><B>&nbsp;</B></P>

<P STYLE="font: 14pt Arial, Helvetica, Sans-Serif; margin: 0; text-align: center"><B>&nbsp;</B></P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify"><B>Buenos Aires, March 8, 2024, </B>The Board
of Directors of Empresa Distribuidora y Comercializadora Norte S.A. (&#8220;<B>Edenor</B>&#8221; or the &#8220;Company&#8221;) approved
today its financial statements for the year ended December 31, 2023, which show a profit of ARS 48,371 million.</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify"><B>&nbsp;</B></P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">In April and June 2023 there were electricity
rate adjustments, which implied an increase in the Distribution Own Cost (CPD), and resulted in an improvement in the Company&#8217;s
distribution margin. Although the adjustments were insufficient to cover inflation of the rest of the year, the investments necessary
for maintaining the quality of the service continued to be made, which was reflected in the levels reached by our SAIDI and SAIFI indicators,
as well as in the satisfaction levels of our customers.</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 10pt Times New Roman, Times, Serif; margin-top: 0; margin-bottom: 0; text-align: center"><IMG SRC="edn202403116k1_002.jpg" ALT=""></P>

<P STYLE="margin: 0"></P>

<P STYLE="margin: 0">&nbsp;</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 14.2pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 0pt; text-align: justify">After the Public Hearing held for such purpose
on last January 26, 2024, the ENRE approved Resolution No.102/2024, which set the new values applicable to the Distribution Own Cost (CPD),
as well as the new Electricity Rate Schedule, effective as from February 16, 2024. Such provisions imply an increase in the Distribution
Own Cost of 319.2%, and include an automatic adjustment mechanism applicable as from May 2024, in order to avoid mismatches and adjustments
that would affect users.</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 14.2pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 0pt; text-align: justify">The approved changes will make it possible,
both to continue making investments to improve service quality, with technology and innovations, promoting a responsible and efficient
use of energy, and, in turn, to continue balancing the Company&#8217;s finances, including the ongoing concern concept.<BR STYLE="clear: both">
</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0; text-align: justify"><B>MAIN FINANCIAL INDICATORS OF 2023</B></P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">The prior-year&#8217;s figures have been
restated to reflect the changes in the purchasing power of the Argentine peso, in accordance with International Accounting Standard No.
29 and the provisions of General Resolution No. 777/2018 of the National Securities Commission.</P>

<P STYLE="font: 8pt Arial, Helvetica, Sans-Serif; margin: 0 28.35pt 0 21.3pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 10pt Times New Roman, Times, Serif; margin-top: 0; margin-bottom: 0; text-align: center"><IMG SRC="edn202403116k1_003.jpg" ALT=""></P>

<P STYLE="font: 6pt Arial, Helvetica, Sans-Serif; margin: 0 28.35pt 0 7.1pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 10pt Arial, Helvetica, Sans-Serif; margin: 0 28.35pt 0 21.3pt; text-align: justify">(*) In 2023 and 2022, includes the
effect of the Agreement on the Regularization of Payment Obligations for ARS 197,731 million and ARS 56,579 million, respectively.</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">Both, <B>revenue</B> and the <B>distribution
margin </B>reflected increases in real terms of 9% and 24%, respectively, compared to the previous year, as a consequence of the increase
in the CPD resulting from the new electricity rate schedules effective as from the April and June 2023.</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">The <B>EBIT</B> resulted in a profit of ARS
77,945 million. Without taking into consideration the results deriving from the Agreement on the Regularization of Payment Obligations,
the <B>EBIT</B> would amount to a loss of ARS 119,786, which reflects the increase in the Company&#8217;s operating costs.</P>

<P STYLE="font: 10pt Times New Roman, Times, Serif; margin: 0 0 0 3.3pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">The <B>profit for the year</B> as of December
31, 2023 amounted to ARS 48,371 million, including the effects of the payment plans on the debt with CAMMESA for energy purchased.</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">As for <B>Investments</B>, in 2023 period,
they amounted to ARS 123,628 million, which in constant values represents 17% more than the investments recorded in 2022. This indicates
that Edenor continued giving priority to its investment plan with a direct positive impact on the quality of the service.</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify"><B>OPERATING INDICATORS</B></P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify">&nbsp;</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify"><B>Electricity sales</B> in 2023 increased
3.1% to 23,538 GWh, as compared to the 22,826 GWh sold in the previous year, whereas the level of customers increased by 1.0%.</P>

<P STYLE="font: 11pt Arial, Helvetica, Sans-Serif; margin: 0 0 0 3.3pt; text-align: justify"><B>&nbsp;</B></P>
